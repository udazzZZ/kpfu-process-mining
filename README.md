# KPFU Process Mining

Frontend-приложение для процессной аналитики.
Сервис позволяет загружать журналы событий, настраивать модель данных, создавать отчёты и визуализировать карту процесса.


## Возможности

* регистрация и авторизация пользователей;
* создание и просмотр проектов;
* создание моделей данных;
* загрузка журналов событий в форматах `.xes`, `.csv`, `.xlsx`;
* предпросмотр загруженного файла;
* настройка типов колонок;
* выбор ключевых полей процесса: case id, activity, timestamp;
* работа с атрибутами данных;
* создание отчётов на основе модели данных;
* визуализация карты процесса в виде интерактивного графа.

## Запуск проекта

В проекте используется Node.js версии `22.14.0`.

Установка зависимостей:

```bash
npm i
```

Запуск проекта:

```bash
npm run dev
```

## Работа с backend

Для работы с локальным backend необходимо переименовать файл `.env.example` в `.env` и указать URL локально развернутого сервера:

```env
VITE_API_URL=http://localhost:8000
```

## Сборка

```bash
npm run build
```
